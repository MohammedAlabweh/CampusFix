# Staff dashboard

React web dashboard for Accommodation Services and Estates staff.

MVP features:

- Staff sign in
- Queue sorted by priority then age, filtered by area (halls or campus), team, building and status
- Ticket detail: description, photo, AI suggestions and confidence, location
- Time left against UWE's response targets (4 hours, 8 hours, 7 days)
- Correct category or priority, assign a team, update status, add a note for the student

Development starts in phase 4 (January 2027).
