# API

.NET / C# backend with a PostgreSQL database.

Responsibilities:

- Students, halls, flats, buildings, rooms and teams (seeded from a config file)
- Reports, statuses and staff notes
- Calls the AI service to classify new reports
- Routing: halls reports to Accommodation Services, campus reports to the matching Estates team
- Printable QR codes for campus rooms

Design is produced in phase 3; development starts in phase 4.
